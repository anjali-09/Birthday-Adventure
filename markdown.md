# OPERATION 29 - PROJECT CONTEXT

## Project Overview

Interactive birthday website for a male best friend turning 29.

Theme:

* Travel Adventure
* Birthday Mission
* Agent / Explorer vibe
* One-page experience
* Mobile-first design
* Hosted via GitHub Pages or Netlify

Project Name:

OPERATION 29
or
Adventure 29

Tagline:

"Your birthday has started. So has the game."

---

## Story Concept

The birthday person has just turned 29.

To celebrate, they must complete:

* 29 Levels
* 29 Challenges
* 29 Surprises
* 29 Memories

Each level represents a travel checkpoint or destination.

Completing a level unlocks a reward.

Rewards may include:

* Photos
* Videos
* Audio Messages
* Letters
* Roasts
* Memories
* Hidden Messages

The final level unlocks a large birthday surprise.
